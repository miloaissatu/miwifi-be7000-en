Host allowlist

The extension only translates pages that look like a MiWiFi router interface. Optionally restrict it further to specific hosts. One entry per line (or comma separated). * matches any characters. Default: * (any host).

  • 192.168.31.1 – exactly this address
  • 192.168.* – any 192.168.x.x address
  • router.lan – exactly this name
  • *.lan – any name ending in .lan
  • 192.168.31.1:8080 – include a port to match only that port

Reload open router pages after changing this.
